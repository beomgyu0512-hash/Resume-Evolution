# Resume Evolution · 简历优化

> 上传简历和目标岗位要求，找出匹配优势，补充关键经历，再完成有针对性的改写。

`resume-evolution` 是一个面向实习、应届和初级岗位的简历优化 Skill，支持中文和英文简历。它会先分析招聘需求，再结合你的真实经历，完成诊断、事实确认、改写和复查。

你会得到岗位分析、可填写的事实确认单、修改前后对照，以及按统一样式排版的完整简历。

当前版本：**2.2.0**。

## 快速开始

安装后，上传以下两份材料：

- **待优化简历**：PDF、Word、截图或文本。
- **目标岗位要求（JD）**：官网或招聘网站上的完整截图、文字，也可以提供岗位链接。

然后对 AI 说：

```text
使用 resume-evolution。我上传了简历和目标岗位要求，请先完成第一步，并生成 Markdown 事实确认单，等我填写后再继续。
```

如果文件或链接无法读取，直接粘贴文字即可。

## 三步完成简历优化

### 第一步（共三步）：看懂岗位，找出简历的提升空间

AI 会先阅读岗位要求，找出：

- **招聘中最重要的五个词或概念**，以及它们为什么重要。
- **公司寻求的实际技能**：需要完成什么任务、使用什么方法、交付什么结果。
- **这次招聘可能想解决的问题**，并说明判断依据。

接着对照你的简历，给出初始匹配评分和具体分析：

| 你会看到什么 | 能帮你了解什么 |
| --- | --- |
| 匹配评分与分项说明 | 当前材料与岗位要求的匹配情况 |
| 关键词差距与主要减分项 | 哪些内容需要补充、解释或调整 |
| 岗位问题与经历对照 | 你的哪些经历能证明你可以解决相关问题，关联程度如何 |
| 空间价值检查 | 哪些信息值得突出，哪些表述可以压缩、合并或删除 |

这一步结束时，AI 会生成 **`事实确认单.md`**，列出需要你补充的事项，并暂停等待填写。

### 填写事实确认单

在每个事项的冒号后，直接用自然语言回答。可以描述自己学过什么、独立做过什么、在项目中负责什么，以及结果如何衡量。

例如：

```markdown
1. SQL 多表查询与汇总：
跟着课程写过连接查询，能完成基础汇总，还没有在实际项目中使用。

2. 订单分析项目中的个人贡献：
我独立整理了 3 家门店、8 周的订单，用 Excel 透视表制作周报。

3. 报表效率提升的依据：
没有记录具体耗时，但可以说明处理步骤和最终交付内容。
```

不熟悉或没做过的内容可以如实说明，暂时不确定的也可以先跳过。填好后，把文件上传回来，或直接粘贴回答，AI 就会进入第二步。

### 第二步（共三步）：把真实经历写清楚

AI 会结合你的补充，按 XYZ 思路改写经历：

> 完成了什么（X），通过什么衡量（Y），采用什么方法实现（Z）。

有实际指标时写清指标与口径；没有数字时，可以突出交付物、工作范围、方法和验证结果。

这一阶段会输出：

- **修改前后对照**：原文、改写结果和修改理由。
- **完整简历草稿**：自然融入有经历支持的岗位关键词，突出个人贡献，精简重复和无关内容。

### 第三步（共三步）：复查并重新评分

AI 会从两个视角复查：

- **ATS 筛选视角**：检查板块、关键词和文字可读性。
- **招聘官快速阅读视角**：检查能否迅速看出你的相关经验、个人贡献和成果。

修订后，AI 会使用同一套评分标准，对最终简历重新独立打分，再展示初始与最终评分的对照及变化原因。

最后交付完整简历、HTML 排版预览、仍需补足的内容，以及可以提前准备的面试追问。具备导出工具时同时生成 PDF。

## V2 简历样式

采用白底、单栏正文和清楚的文字层级，右上角放证件照。姓名26pt；正文按内容从10.5pt逐级缩小，最低9pt。教育经历日期直接写年月，例如“2023.09—2027.06”，不附“（预计毕业）”。左右页边距14mm、上下12mm；每条正文最多强调两处。带日期的经历采用左日期、右名称，板块标题下配通栏细线；技术栈单独成行，技能按加粗类别展开。

| 主题 | 浅色点缀 | 深强调色 |
| --- | --- | --- |
| 浅蓝绿（默认） | `#E7F3F1` | `#39766F` |
| 浅绿 | `#EDF4E8` | `#58754C` |
| 浅粉 | `#F8EBEF` | `#975F73` |
| 浅黄 | `#FAF3DE` | `#8B743B` |
| 浅蓝 | `#EAF1FA` | `#4D7099` |

第一步时可以选择颜色并上传证件照。未选颜色就使用浅蓝绿，照片尺寸为27×36mm；暂时没有照片也可以先完成内容和预览。用户可明确选择不放照片。

主题色点缀标题细线、小色块、岗位文字和照片衬底，正文统一深灰。优先在一页内选取能容纳内容的最大字号，短内容保留留白。最小字号仍放不下时，明确提示内容过多，并给出精简建议或两页方案。

固定模板位于 `skills/resume-evolution/assets/resume/`，详细排版规则见 `references/design.md`。HTML 渲染器仅使用 Python 标准库，PDF 导出使用现有浏览器或文件工具。

`examples/previews/` 提供凯尔希角色履历的两份默认浅蓝绿示例：最大正文10.5pt、最小正文9pt。最大字号版展示精简履历，最小字号版补充医疗培养与具体任务经历，展示更多内容的一页排版；资料来源见 `examples/SOURCES.md`。

开发者可用虚构数据生成预览：

```bash
python3 skills/resume-evolution/scripts/render_resume.py examples/layout-input.json preview.html --draft --theme teal
```

换色使用 `green`、`pink`、`yellow` 或 `blue`；带照片使用 `--photo /本地路径/证件照.png` 并去掉 `--draft`。照片会嵌入输出文件。浏览器需启用 JavaScript，等待页面提示字号计算完成后再打印；交付说明会列出实际字号和PDF页数。

## 附加：岗位筛选与申请准备

第三步结束后，AI 会询问你是否需要继续准备申请。回答“需要”后，补充城市、到岗时间等条件，即可筛选最多十个匹配岗位，并准备对应的简历调整建议和沟通草稿。

你也可以直接提供岗位截图或链接清单：

```text
根据我的城市和到岗条件，从这些岗位中筛选最多十个匹配岗位，帮我准备申请材料，先不发送。
```

## 按你的节奏使用

**想先快速改一版：**

```text
使用 resume-evolution，不追问，基于现有事实直接改写，并把待确认事项列在简历正文之外。
```

**想针对另一个岗位继续优化：**

```text
这是新的岗位要求，请复用已经确认的个人经历，为这个岗位单独分析并生成新的简历版本。
```

**想接着上次的进度做：**

```text
读取当前岗位的分析、已确认事实和进度记录，从上次停下的地方继续。
```

在可以读写文件的环境中，Skill 会保存已确认事实、待确认事项、当前阶段和各岗位的简历版本，方便后续继续使用。

## 安装

实际 Skill 文件夹位于：**`skills/resume-evolution/`**。

1. 下载并解压项目包。
2. 将整个 `resume-evolution` 文件夹放入 AI 工具支持的 Skill 目录，或通过该工具的导入功能选择这个文件夹。
3. 保留文件夹内的 `SKILL.md`、`references/`、`agents/`、`assets/` 和 `scripts/`。
4. 安装后，通过 `resume-evolution` 调用。

如果你的 AI 工具支持本地文件，也可以让它读取 `SKILL.md` 及其中引用的规则文件，按流程处理简历。

Skill 本身不需要额外配置 API Key 或安装 Python 包。网页浏览、截图识别和 Word/PDF 导出使用所在 AI 工具提供的能力。

**旧版更新：**将原来的 `resume-evidence` 文件夹替换为 `resume-evolution`。
