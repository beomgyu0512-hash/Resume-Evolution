# Resume Evidence · 简历有据

上传一份待优化简历 + 一份目标岗位需求，得到有事实依据的简历优化。

版本：1.0.0。中文优先，也可处理英文。主要面向实习、应届和初级岗位，资深岗位需另做验证。

## 使用前准备
- 简历：PDF、Word、截图或文本。是否能读取取决于宿主工具；最稳妥的是提供文本。
- JD：官网/招聘网站完整截图或文字，包含任职要求；也可提供可访问链接。
- 可选补充：个人贡献、真实指标及口径、项目性质、作品链接、到岗条件。
- 分享案例前脱敏；不要上传身份证、密码、验证码。模型服务仍会处理你提供的材料，并不因为 Skill 文件在本地就变成离线运行。

## 安装与调用
ZIP 是发布项目包，实际 Skill 位于 `skills/resume-evidence/`。
将该完整目录放入宿主支持的 Skill 目录，保留 SKILL.md、references 和 agents。若宿主支持导入文件夹，选择该目录。不同工具的安装入口以其当前说明为准。
无需 API Key、额外 Python 包或专属 MCP；需要一个能读取 SKILL.md 的 AI 助手。浏览网页、OCR、Word/PDF 导出是可选的宿主能力。
不能安装时：让助手读取 SKILL.md，并按需要读取 references 下文件；仅粘贴主文件可能遗漏评分细则。

调用示例：
“使用 resume-evidence。我上传了简历和目标岗位 JD，请先诊断，必要时每轮追问最多三个问题，再改写和复查。”
直接处理：“不追问，基于现有事实完成保守改写，并将待确认项列在正文外。”
可选步骤：“根据我的城市和到岗条件，筛选最多十个匹配岗位，准备申请材料，先不发送。”

## 四步流程
1. 招聘官视角：100 分固定量表，最多五个关键词缺口、三个减分项。
2. 事实确认与 XYZ 改写：给出对照及理由，再生成完整版本。
3. ATS 与快速阅读模拟：复查关键词、结构、事实和可读性。
4. 可选岗位筛选：最多十个可核实岗位与申请草稿。

评分是基于所给材料的启发式评价，不是面试概率或真实 ATS 评分。未写明不等于不会，能力缺口不能靠润色消除。文件/岗位访问失败会明确标注。

## 看示例和测试
`examples/` 是明确虚构的教学案例，不得用于真实求职。
`tests/acceptance.md` 是行为验收清单；`tests/RESULTS.md` 记录本版本实际验证范围。
可用 `python3 tests/check_package.py` 检查文件结构、内部引用和评分权重。这不能代替真实模型行为测试。

## 发布到 GitHub
将本目录内容作为仓库根目录，保留 skills 结构。先检查没有真实简历、联系方式、访问令牌及用户产物，再选择许可证并公开。
本包未预设开源许可证；公开发布前请作者选择 LICENSE。没有许可证不等于允许他人任意复制。
仓库简介建议：基于简历与 JD 的事实驱动优化 Skill：匹配诊断、XYZ 改写、ATS 模拟复查及岗位申请准备。
如果它帮你把项目经历讲得更清楚，欢迎 Star；也欢迎通过脱敏案例反馈问题。

## 贡献
提交问题时提供宿主/模型、脱敏输入、实际输出和期望行为。不要附他人的真实简历。修改评分规则时更新版本并重新测试。
