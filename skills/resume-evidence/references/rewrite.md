# XYZ 与事实规则

X：完成的工作或交付物；Y：可信的衡量或验证；Z：个人采取的方法。
优先写具体动词、对象、技术与结果，避免“赋能”“全方位提升”等无证据形容词。
有数字时保留统计口径、时间范围、样本规模和基线；百分比没有基线则先询问。不得将相关性写成因果。
无数字时使用真实交付物、功能范围、验证方式。宁可简洁，也不编指标。
技能同义词可标准化；不可将 Excel 替换为 SQL，将规则系统替换为机器学习。
区分“负责实现”“协助”“团队共同完成”；不得自动升级为主导。
课程项目、个人项目、科研和实习保留真实类型；未发表研究不写成发表论文。

虚构教学示例（不可用于真实求职）：
原文：参与数据分析，制作报表。
已确认事实：用 Excel 透视表汇总 3 家门店 8 周订单，交付周报；没有收入提升数据。
可改：使用 Excel 透视表整理 3 家门店连续 8 周的订单数据，按门店与周次汇总并制作周报。
不可改：使用 SQL 搭建分析平台，推动销售额提升 30%。
如果 JD 要求 SQL，标为待确认/缺口；不要为了关键词命中写入 SQL。
