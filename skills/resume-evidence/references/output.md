# 输出约定

默认聊天交付；用户要求文件时保存为独立版本，不覆盖原简历。文件能力不足时交付可复制 Markdown。

1. 输入状态：简历、JD 来源与完整性；截图识别疑点。
2. 诊断：分项评分表、总分及限制、硬条件、最多五个关键词和三个减分项。
3. 追问：每轮最多三个；不重要的未知项不阻塞已有内容改写。
4. 关键改写对照：原文｜改写｜理由｜事实依据。事实编号来自用户材料，不伪造外部引文。
5. 完整简历：只放可投递内容，不混入诊断、评分、内部事实编号或待补占位符。
6. 复查：ATS 模拟、招聘官阅读、文件级检查状态、剩余差距。
7. 面试核验：最多三个基于改写内容的具体问题。

建议文件：diagnosis.md、changes.md、resume.md、review.md。按 JD 分目录；不得把私人结果放入 Skill 自身目录或公开仓库。
未提供联系方式等必要信息时，可交付内容草稿并在正文外明确缺项，不声称可直接投递。
