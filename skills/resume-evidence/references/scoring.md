# 评分标准 v1

评分描述材料中可见的匹配程度，不是招聘决策预测。固定权重，不根据希望得到的分数调整。

| 维度 | 权重 | 内容 |
|---|---:|---|
| 岗位明确要求 |30| 学历、专业、经验、到岗条件、资格 |
| 核心技能 |25| JD 明确技能及实际使用证据 |
| 相关经历 |25| 实习/项目任务与岗位工作关联 |
| 成果与个人贡献 |15| 本人动作、交付物、验证方法、结果 |
| 表达与可读性 |5| 结构清楚、语言具体、时间一致 |

对前三个维度，将 JD 中不重复的要求分配到最相关维度，避免重复扣分；维度内明确必需项权重 2、加分项权重 1。每项系数：明确证据 1、部分满足 0.5、未体现/明确不满足 0。后两者虽暂时同分，结论必须区分。
维度分=维度权重×Σ(要求权重×系数)/Σ要求权重。没有列明要求的维度标 N/A：展示已评估得分/已评估满分；如转换成百分制，明确标“可评估部分标准化分”，不冒充完整 100 分匹配评分。
成果维度按个人贡献、交付物、验证/结果三项各 5 分，充分/部分/无证据分别 5/2.5/0。不强制业务数字，可靠的定性验证同样可得分。
表达维度按结构、清晰、相关性、时间一致、简洁五项各 1 分，可取 0/0.5/1。
保留一位小数，显示算式或分项，核对总和。对识别不清且影响硬条件的信息不评分，先确认。
另报证据覆盖：JD 要求中明确或部分有证据的条目数/总条目数，不称之为预测准确率。
硬性条件不满足单独醒目标注，不能被高总分掩盖。职位未提的年龄、性别、婚育等不纳入评价。毕业时间只用于实际可核实的招聘资格。
关键词表列“JD 原文｜简历证据｜状态｜能否写入｜需补充什么”。最多五项；没有缺口可以为零。
