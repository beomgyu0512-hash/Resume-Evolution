# 可选：岗位筛选与申请准备

先获取城市/远程偏好、岗位方向、求职类型、到岗时间、每周出勤、持续时间与用户指定薪资约束。没有给出的约束不能代填。
用户明确要求访问 BOSS 直聘时，先检查可用连接器或浏览器。需要登录由用户自行完成，不索取凭据，不绕过验证码、访问控制或平台限制。没有访问能力时使用岗位截图/链接清单。
仅基于用户提供或实际访问的岗位建表，保留原始 URL、公司、岗位、地点、获取日期和可见状态。去重；少于十个就交付实际数量，不凑数。
应用 scoring.md 的固定标准评估；先剔除明确不满足的硬条件（另列原因），再按匹配分、证据完整程度和用户偏好排序。无法核实条件标待确认。
每项输出：排名、岗位/公司、来源、硬条件、得分依据、优势、差距、简历调整建议和简短沟通草稿。草稿只能使用真实经历。
默认仅准备材料。实际发送、投递、添加联系人需用户明确授权具体范围，并遵守宿主权限；已授权事项不重复索要确认。发送前确认目标与附件对应，记录发送或投递的结果。
