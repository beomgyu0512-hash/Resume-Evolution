# 评分标准 v1

按材料中可见的匹配程度评分，使用固定权重。

| 维度 | 权重 | 内容 |
|---|---:|---|
| 岗位明确要求 |30| 学历、专业、经验、到岗条件、资格 |
| 核心技能 |25| JD 明确技能及实际使用证据 |
| 相关经历 |25| 实习/项目任务与岗位工作关联 |
| 成果与个人贡献 |15| 本人动作、交付物、验证方法、结果 |
| 表达与可读性 |5| 结构清楚、语言具体、时间一致 |

对前三个维度，将 JD 中不重复的要求分配到最相关维度，避免重复扣分；维度内明确必需项权重 2、加分项权重 1。每项系数：明确证据 1、部分满足 0.5、未体现/明确不满足 0。后两者虽暂时同分，结论必须区分。
维度分=维度权重×Σ(要求权重×系数)/Σ要求权重。没有列明要求的维度标 N/A：展示已评估得分/已评估满分；如转换成百分制，标为“可评估部分标准化分”。
成果维度按个人贡献、交付物、验证/结果三项各 5 分，充分/部分/无证据分别 5/2.5/0。不强制业务数字，可靠的定性验证同样可得分。
表达维度按结构、清晰、相关性、时间一致、简洁五项各 1 分，可取 0/0.5/1。
保留一位小数，显示算式或分项，核对总和。对识别不清且影响硬条件的信息不评分，先确认。
另报证据覆盖：JD 要求中明确或部分有证据的条目数/总条目数。
硬性条件不满足单独醒目标注，不能被高总分掩盖。职位未提的年龄、性别、婚育等不纳入评价。毕业时间只用于实际可核实的招聘资格。
关键词表列“JD 原文｜简历证据｜状态｜能否写入｜需补充什么”。最多五项；没有缺口可以为零。


## 初始与最终评分：独立重新计算

第一步根据 JD 建立评分条目、所属维度、必需/加分权重、N/A处理，并冻结为本岗位 rubric。推测的公司问题不得当作明确要求计分。初始分对原简历评分；用户后来提供的确认不追溯修改初分。
第三步完成最后一次改写后，先仅使用同一 JD、冻结 rubric、最终简历及核实该版本主张所需的事实来源，逐项从零判断系数、计算各维度和总分。不得读取初始得分后加减，不设目标分，不要求优化后一定提高。
若可用独立子代理，给其JD、rubric、最终简历与事实来源，不提供初分、旧评分理由或目标分；无此能力时，同一助手使用空白评分表逐项重算。
最终评分完成后，才对照初始评分：区分新增且已写入简历的真实事实、原有证据表达更清楚、版式改善或先前误判。只补充在对话中而未体现在最终简历的能力，不能作为招聘者可见证据加分。
能力和经历分不得仅因关键词变多上涨；原先模糊的证据被具体化后可重判，但必须说明对应证据。允许最终分不变或下降。
核对条目、权重和加总；发现初始算术错误时保留原记录，另列更正。JD变化需创建新评分任务，禁止直接比较不同基准。
使用一致量表，保留评分证据，统一处理未知项，并独立重算。
